# Yelp-New-Orleans-Project

## Region choice

I chose New Orleans as my study region because the Yelp dataset contains a large number of restaurants in the area, making it possible to compare restaurant categories, ratings, and locations. I focused on Cajun/Creole, seafood, and Southern restaurants because these categories are closely connected to New Orleans food culture.

For the geographic analysis, I chose Census tracts as my primary system because they divide New Orleans into smaller areas, allowing for more detailed comparisons. I also compared Census tracts with ZIP Code Tabulation Areas to show how different geographic boundaries can affect the results.
